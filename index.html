# PEMBUATAN APLIKASI KATALOG JERSEY ONLINE TERINTEGRASI WHATSAPP Buatkan aplikasi web katalog jersey profesional, modern, responsif, dan mudah digunakan melalui HP maupun komputer. Aplikasi ini khusus untuk penjualan jersey custom, jersey bola, futsal, voli, jersey merpati, dan produk apparel lainnya. Nama aplikasi: **KATALOG JERSEY ONLINE** ## 1. TAMPILAN HALAMAN UTAMA (PELANGGAN) Buat tampilan katalog yang elegan, modern, profesional, dan menarik. Fitur: - Logo toko di bagian atas. - Nama toko dan informasi kontak. - Banner promosi. - Kolom pencarian produk. - Kategori produk: - Jersey Bola - Jersey Futsal - Jersey Voli - Jersey Merpati - Jersey Custom - Produk Lainnya - Tampilan produk berbentuk grid. - Foto produk berkualitas tinggi. - Nama produk. - Kode produk. - Harga produk. - Tombol Lihat Detail. - Tombol Pesan Sekarang melalui WhatsApp. ## 2. DETAIL PRODUK Setiap produk memiliki: - Foto produk utama. - Galeri beberapa foto produk. - Nama produk. - Kode produk. - Deskripsi produk. - Pilihan warna jika tersedia. - Pilihan ukuran. - Harga satuan. - Tombol pesan melalui WhatsApp. ## 3. PANEL ADMIN Buat halaman login admin yang aman. Username dan password dapat dikelola oleh admin. Fitur admin: - Login dan logout. - Mengganti password kapan saja. - Mengganti username. - Dashboard statistik produk dan pesanan. - Upload foto produk. - Mengedit foto produk. - Menghapus foto produk. - Upload beberapa foto sekaligus. - Menambahkan produk baru. - Mengedit nama produk. - Mengedit harga produk. - Mengedit deskripsi. - Mengedit kategori. - Mengedit kode produk. - Mengaktifkan dan menonaktifkan produk. - Menghapus produk. - Mengatur banner promosi. - Mengubah nomor WhatsApp toko. Semua perubahan yang dilakukan admin harus otomatis tersimpan ke database dan langsung tampil di halaman katalog pelanggan. Gunakan penyimpanan gambar berbasis cloud storage agar foto produk tidak hilang ketika aplikasi diperbarui. ## 4. KALKULATOR DP OTOMATIS Buat fitur kalkulator DP berdasarkan jumlah baju yang dipesan. Aturan DP harus mengikuti tabel berikut secara tepat: | Jumlah Baju | DP | |---|---:| | 1–3 baju | Rp50.000 | | 4–6 baju | Rp150.000 | | 7–12 baju | Rp250.000 | | 13–24 baju | Rp300.000 | | 25–50 baju | Rp500.000 | | 51–100 baju | Rp1.000.000 | Ketentuan: - Pelanggan memasukkan jumlah baju. - Sistem otomatis menentukan nominal DP. - DP langsung berubah ketika jumlah baju diubah. - Tampilkan jumlah baju. - Tampilkan nominal DP yang harus dibayar. - Format rupiah menggunakan format Indonesia. - Jika jumlah baju lebih dari 100, tampilkan pesan untuk menghubungi admin. - Jumlah baju tidak boleh kurang dari 1. Contoh: Pelanggan memesan 10 baju, sistem otomatis menghitung DP sebesar Rp250.000. ## 5. INTEGRASI WHATSAPP OTOMATIS Hubungkan aplikasi dengan WhatsApp toko: Nomor WhatsApp: **085126260240** Gunakan format internasional Indonesia: 6285126260240. Setiap produk memiliki tombol Pesan via WhatsApp. Ketika pelanggan menekan tombol tersebut, sistem otomatis membuka WhatsApp dengan pesan yang sudah terisi. Contoh pesan: Halo Admin, saya ingin memesan produk jersey. Nama Produk: [Nama Produk] Kode Produk: [Kode Produk] Jumlah Pesanan: [Jumlah Baju] Harga Satuan: [Harga] Total Pesanan: [Total Harga] DP yang Harus Dibayar: [Nominal DP] Mohon informasi selanjutnya untuk proses pemesanan. Terima kasih. Gunakan WhatsApp Click to Chat dengan URL: https://wa.me/6285126260240 Pastikan pesan otomatis menggunakan URL encoding agar tidak terjadi kesalahan karakter. ## 6. FORM PEMESANAN Buat formulir pemesanan yang berisi: - Nama pemesan. - Nomor WhatsApp pemesan. - Nama produk. - Kode produk. - Jumlah baju. - Total harga. - Nominal DP otomatis. - Catatan tambahan. - Tombol Kirim Pesanan ke WhatsApp. Setelah tombol ditekan, buka WhatsApp dengan seluruh informasi pesanan yang sudah dirangkum. ## 7. DESAIN APLIKASI Gunakan desain: - Modern dan minimalis. - Dominasi warna hitam, putih, dan aksen emas. - Tampilan premium. - Navigasi sederhana. - Foto produk menjadi fokus utama. - Responsif untuk HP, tablet, dan komputer. - Loading cepat. - Tampilan katalog seperti toko online profesional. ## 8. TEKNOLOGI DAN DATABASE Gunakan teknologi modern: - Frontend: React atau Next.js. - Database: Supabase. - Authentication: Supabase Auth. - Penyimpanan foto: Supabase Storage. - Desain responsif. - SEO-friendly. - Keamanan panel admin. - Validasi formulir. - Proteksi halaman admin. Pastikan pelanggan hanya bisa melihat katalog dan membuat pesanan, sedangkan hanya admin yang dapat mengelola produk, foto, harga, dan pengaturan aplikasi. ## 9. FITUR TAMBAHAN Tambahkan: - Tombol WhatsApp mengambang di halaman utama. - Katalog dapat dibagikan melalui link. - Setiap produk memiliki link detail sendiri. - Admin dapat melihat daftar pesanan. - Admin dapat mengubah status pesanan. - Status pesanan: Menunggu DP, DP Dibayar, Diproses, Selesai. - Riwayat pesanan tersimpan di database. - Tombol salin link produk. - Produk terbaru otomatis tampil paling atas. ## 10. Tombol pemesanan terhubung ke WhatsApp 085126260240. 8. Pesan WhatsApp otomatis berisi detail pesanan. 9. Aplikasi bisa diakses melalui link website. 10.
